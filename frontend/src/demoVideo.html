Kite Passport (MCP)

Identity + wallet + spending rules. The agent calls get_payer_addr and approve_payment via MCP to authorize each transaction without exposing private keys.

x402 Protocol (gokite-aa)

HTTP-native payment negotiation. The 402 challenge contains the complete bill — amount, token, network, recipient — that any compliant agent can read and respond to automatically.

USDC.e on Kite Testnet

The settlement currency. Contract 0x0fF539...e63 on Chain 2368. Pieverse calls transferWithAuthorization to move funds without requiring the agent to pay gas.

GoPlus + Bytecode Analysis

Production scanner integrates GoPlus Security API for real-time threat intelligence, combined with on-chain bytecode analysis to detect honeypots, drainers, and rug pull patterns.
